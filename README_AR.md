# مشغل السيارة (Car MP3)

تطبيق أندرويد يظل خاملاً، ويستيقظ فقط عند اتصال بلوتوث السيارة، ثم يشغّل ملفات MP3 من مجلداتك ويتحكم فيها من أزرار السيارة.
لا يحتاج أي مكتبات خارجية، ولا يحتاج برنامج Android Studio: يُبنى (يُعمل له Compile) على سيرفر GitHub مجاناً.

---

## أسهل طريقة للحصول على ملف APK (بدون تثبيت أي برنامج)

1. أنشئ حساباً على github.com (مجاني)، ثم **New repository** باسم `CarMp3` (يمكن جعله Private).
2. افتح المستودع واضغط **uploading an existing file**، ثم اسحب **محتويات** هذا المجلد كلها (بما فيها مجلد `.github`) وأفلتها، ثم **Commit changes**.
   - إذا لم يظهر مجلد `.github` بعد الرفع: اضغط **Add file ← Create new file**، اكتب في خانة الاسم
     `.github/workflows/build.yml` والصق محتوى ملف `build.yml` الموجود داخل المجلد نفسه.
3. افتح تبويب **Actions**؛ سيبدأ البناء تلقائياً (يستغرق 4-6 دقائق أول مرة). لو لم يبدأ: Build APK ← **Run workflow**.
4. عند ظهور علامة ✅ ارجع للصفحة الرئيسية للمستودع ← **Releases** (على اليمين) ← آخر إصدار ← نزّل `CarMp3.apk` **مباشرة على الهاتف**.
5. ثبّته (اسمح بالتثبيت من هذا المصدر). قد تظهر رسالة Play Protect لأن التطبيق غير منشور في المتجر؛ اختر "تثبيت على أي حال".

> أي تعديل ترفعه لاحقاً على المستودع يبني APK جديداً تلقائياً.

بديل: افتح المجلد في Android Studio واضغط Build ← Build APK.

---

## أول تشغيل على هونر 90 (مهم جداً)

1. افتح التطبيق مرة واحدة، وامنح إذن **الأجهزة القريبة** و**الإشعارات**.
2. اضغط **إلغاء تقييد البطارية** داخل التطبيق.
3. الإعدادات ← البطارية ← **تشغيل التطبيقات (App launch)** ← مشغل السيارة ← **إدارة يدوية**، وفعّل الثلاثة:
   التشغيل التلقائي، التشغيل الثانوي، التشغيل في الخلفية.
4. أضف **مسار الموسيقى** من الزر داخل التطبيق ثم **إعادة فحص**.
5. اضغط **إضافة جهاز بلوتوث** واختر السيارة (الأجهزة المتصلة حالياً تظهر في الأول بعلامة 🟢).
   أي جهاز اسمه يحتوي `Captiva` أو `Chevrolet` يُعتمد تلقائياً حتى لو لم تضفه.
6. لا تستخدم **Force stop** على التطبيق؛ لأن النظام يوقف استقبال أحداث البلوتوث بعدها حتى تفتحه يدوياً.

## كيف يعمل (ملخص)

| الميزة | التنفيذ |
|---|---|
| الخمول التام | مستقبِل `BtReceiver` فقط يستيقظ عند ACL_CONNECTED؛ لا خدمة ولا استهلاك قبلها |
| التحقق من الجهاز | عنوان MAC من القائمة، أو الاسم يحتوي Captiva/Chevrolet، أو خيار "أي جهاز" |
| انتظار الصوت | بعد الاتصال ينتظر ظهور مسار A2DP (حتى 15 ثانية) حتى لا يخرج الصوت من سماعة الهاتف |
| أزرار السيارة | عبر `MediaSession`؛ الضغطة المفردة فورية. `>> << >>` مجلد تالٍ، `<< >> <<` مجلد سابق |
| إيقاف/تشغيل | زر السيارة يوقف ويستأنف فوراً |
| الحفظ | المجلد، الملف، الموضع بالمللي ثانية، وحالة التشغيل/الإيقاف (كل 5 ثوانٍ وعند الفصل) |
| بدء الاتصال | تشغيل دائماً / إيقاف دائماً / استكمال الحالة السابقة |
| شاشة السيارة | العنوان `اسم المجلد - اسم الملف` |
| عند فصل البلوتوث | يحفظ الحالة ويغلق نفسه بالكامل |

### ملاحظات سلوكية
- "المجلد" = أي مجلد يحتوي ملفات صوتية مباشرة (يُفحص ما تحت المسار المضاف تلقائياً بكل مستوياته).
- المقطع التالي/السابق يلتف داخل المجلد (من الأخير للأول وبالعكس).
- لأن الاستجابة فورية، أول ضغطتين من النمط تغيّران المقطع لحظياً ثم تنتقل الثالثة للمجلد الجديد (من أول مقطع فيه).
- مهلة النمط ثانيتان بين كل ضغطة والتي قبلها؛ تغييرها: `PATTERN_GAP_MS` في `PlaybackService.kt`.
- بعض السيارات ترسل أمر Play تلقائياً بمجرد الاتصال، وهذا قد يتجاوز وضع "إيقاف دائماً". هذا من السيارة وليس من التطبيق.
- منتقي المجلدات في أندرويد لا يسمح باختيار جذر التخزين أو جذر مجلد Download؛ اختر مجلداً داخل Music مثلاً.
- خيار "أي جهاز بلوتوث" يعمل فقط إذا ظهر للجهاز مسار صوت، فلن يشغّل الموسيقى لمجرد اتصال ساعة بلا صوت.

## هيكل الملفات
- `BtReceiver.kt` الاستيقاظ والتحقق من الجهاز
- `PlaybackService.kt` المشغّل وأزرار السيارة والحفظ
- `Library.kt` فحص المجلدات
- `Prefs.kt` الإعدادات
- `MainActivity.kt` الواجهة المظلمة
